# Social copy uses OpenAI; video stays on fal

Phase 1 Social Post fields (title/headline, description/body, hashtags, related copy) are generated via OpenAI. Short-form Video rendering remains on fal (including Promo stitch shots). Post Job / AI Post images use fal (`flux-pro/kontext`) behind `IImageGenerationProvider`. Keeps copy and media on the best-fit providers instead of one vendor for everything.
