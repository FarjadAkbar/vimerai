# Products link to many Brand Kits; setup is gated

A Product may be linked to multiple Brand Kits. If the user has only one Brand Kit, new Products are linked to it by default. Users must create a Brand Kit before Products, and must have both a Brand Kit and a Product before Generation. Chosen over single-Brand-Kit-per-Product so agencies can reuse catalog items across client brands, while still forcing a complete brand+product context before generate.
