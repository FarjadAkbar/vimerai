# Fetra-style MVP pivot (separate Post Job / Video Job)

We are pivoting Vimerai from the locked Phase 1/Phase C multi-arm Generation studio (Brand Kit → Social Post + Storyboard + Video) to a Fetra-like ecommerce create loop: Product scrape or manual entry, thin Brand Confirm, curated Format pick, then **Make a Post** or **Make a Video** as separate jobs with Export only. Brand Kit, Generation-as-umbrella, caption packages, storyboard, Posts-only, Length Tiers, Goals, and publish are parked or deprecated in the glossary. Chosen over a UI-only restyle or hybrid so the product matches the volume/viral-format create experience users associate with Fetra, while staying ecommerce-first (Shopify-like URL happy path + manual fallback).

**Status**: accepted (supersedes the Phase 1 B+A and Phase C first-slice roadmap as current product direction; older ADRs remain historical for code that has not yet been migrated)
